Сейчас сайт использует «системные» стеки (Georgia, San Francisco/Segoe/Roboto…). Это означает, что на каждой ОС подставляется свой шрифт: на Apple и Windows заголовки рисует Georgia, а **на Android Georgia нет вообще** — там подставляется Roboto/Noto Serif, и пропорции, переносы строк и сам рисунок букв отличаются. То есть сейчас выглядит «нативно для каждой платформы», но не одинаково.
